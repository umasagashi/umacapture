利用規約

umacapture（以下「このアプリ」）の利用上の約束と免責事項です。このページの内容は、Windows 版と web 版の両方に当てはまります。

1. 運営者と連絡先

運営: umasagashi

連絡先:

  • GitHub: https://github.com/umasagashi/umacapture/issues
  • Discord: https://discord.gg/Ph9hEGHR4M
  • X: https://x.com/umasagashi

2. この規約が当てはまる範囲と、同意

この規約は、Google アカウントでログインして使う機能（アカウント、レコード共有、公開プロフィール・公開メモ、共有レコード一覧の公開、端末間の同期）に当てはまります。共有されたページを見るだけなら、ログインは要りません。

項目 6 の免責事項は、ログインの有無を問わず、このアプリ全体に当てはまります。

ログインすると、この規約に同意したものとみなします。

情報の扱いは、プライバシーポリシーをご覧ください。

3. 運営者が取る措置

運営者は、次の場合に共有を取り下げたり、公開プロフィールを消したりすることがあります。

  • 自分で育成していないレコードや、ほかの人の画像を共有したとき
  • 共有したレコード・画像、公開プロフィール、公開メモに、ほかの人の名前や ID などの個人の情報や、不適切な内容を載せたとき
  • 権利者から申し立てがあったとき

取り下げは、共有全体か、共有した画像だけを対象にします。公開メモは、共有ごと取り下げます。公開プロフィールは、トレーナー名とゲーム内のトレーナー ID を消します。

取り下げや消去をしても同じことを繰り返すとき、意図してほかの人の個人の情報を載せるなど悪質なとき、上限や確認をすり抜けようとするなど、サービスの運営を妨げるときは、アカウントを削除することがあります。削除の範囲は、自分で削除したときと同じです（プライバシーポリシーの項目 6）。

報告だけで消去せず、運営者が内容を見て措置を決めます。

連絡先を保存していないため、措置の前後に運営者からあなたへ通知はしません。措置へのお問い合わせは、項目 1 の連絡先へお願いします。

ほかの人がすでに取り込んだり保存したりしたものは、運営者の措置でも消せません。

4. オンライン機能の停止と変更

運営者は、ログイン・共有・画像共有・同期などのオンライン機能の全部または一部を、予告なく停止・変更することがあります。

オンライン機能は試験公開中です。サーバー上のデータ（共有レコード・同期データを含む）は、予告なく消えることがあります。試験公開を終えるときには、すべて消すことがあります。

5. この規約の変更

運営者は、利用者の利益になる場合、または変更の必要があり内容が妥当な場合に限り、この規約を変更することがあります。変更後の規約と適用日を、適用前にこのページに載せます。

適用日から変更後の規約が当てはまります。

6. 免責事項

umacapture は非公式のツールで、ゲームの開発・運営とは関係ありません。スキル名などゲーム内のテキストの権利は、それぞれの権利者にあります。

運営者は、このアプリの動作やオンライン機能の継続を保証しません。

認識の結果は、まちがうことがあります。

端末のレコードは、お使いの端末（web 版ではブラウザ）の中に保存されます。端末の故障や、ブラウザによるデータの削除で消えることがあります。大事なレコードは、ZIP に書き出して残してください。

あなたがアドオンで設定する外部プログラム・webhook や、スクリプト列の動作・結果は、運営者は保証しません。
