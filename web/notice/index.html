umacapture（web 版）をお使いの方へ

試験公開です

この web 版は試験公開中です。誰でも使えますが、正式な運用ではなく、動作は保証しません。

予告なく止まったり、仕様が変わったりすることがあります。

保存されたデータは、予告なく消えることがあります。試験公開を終えるときには、すべて消すことがあります。

画面や動画はサーバーに送りません

画面や動画の認識はお使いのブラウザの中で行い、サーバーには送りません。

外部への送信

エラー報告: アプリで起きたエラーの情報を Sentry に送ります。初回の起動から送信されます。「設定」画面の「プライバシー設定」にある「利用環境情報の送信許可」をオフにすると送らなくなります（次にアプリを開いたときから反映されます）。

送る内容は、エラーの内容と発生箇所、その直前のアプリの動作記録、アプリの版、ブラウザと OS の種類などです。ファイルの場所に含まれる名前は伏せて送ります。送信元の区別には、この端末で作った無作為の番号を使います（オフにすると消えます）。

エラー報告の仕組みは、Sentry の配信元（browser.sentry-cdn.com）から読み込みます。

フィードバックを送るときは、スクリーンショットが付くことがあります。

フォント: 文字を表示するためのフォントを Google（fonts.gstatic.com）から取得します。このとき IP アドレスなどが Google に渡ります。

認識モジュール・お知らせ: data.umacapture.com から取得します。

Cloudflare: このサイトの配信に使っています。配信事業者として、アクセスの情報（IP アドレスなど）を処理します。

アドオン: アドオンの webhook を設定した場合は、あなたが指定した宛先へ送ります。

その他

umacapture は非公式のツールです。スキル名などゲーム内のテキストの権利は、それぞれの権利者にあります。
