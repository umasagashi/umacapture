umacapture（web 版）をお使いの方へ

試験公開です

この web 版は試験公開中です。誰でも使えますが、正式な運用ではなく、動作は保証しません。

予告なく止まったり、仕様が変わったりすることがあります。

保存されたデータ（共有したレコードや、同期したデータを含みます）は、予告なく消えることがあります。試験公開を終えるときには、すべて消すことがあります。

画面や動画について

画面や動画の認識は、お使いのブラウザの中で行います。動画そのものは送りません。画面や動画から取った画像を送るのは、報告を送る操作をしたときと、端末間の同期で画像を送るとき（下記）だけです。

サーバーに送るのは、共有の操作をしたレコードのデータと、ログインのときの情報（この端末のトレーナー ID を含みます）です。

端末間の同期をオンにした場合は、レコードのデータ（認識の結果と、画像を識別する値）も送ります。「画像の同期」で元の画像か縮小した画像を選んだ場合は、認識に使った画像（ゲーム画面の一部をつないだもの）も送ります。「画像は同期しない」でも、縮小 JPEG でアーカイブしたレコードは、サーバーの画像を置き換える縮小した画像を送ります。

個人情報の扱い

共有と端末間の同期には、Google アカウントでのログインが要ります。サーバーに保存するのは Google アカウントの番号から作った元に戻せない値だけで、メールアドレスや名前は保存しません。

共有したレコードは、URL を知っている人なら誰でも見られます。

エラー報告やフォントの取得など、外部のサービスへの送信もあります。

詳しくは、プライバシーポリシーをご覧ください。
