umacapture（web 版）をお使いの方へ

試験公開です

この web 版は試験公開中です。誰でも使えますが、正式な運用ではなく、動作は保証しません。

予告なく止まったり、仕様が変わったりすることがあります。

保存されたデータ（公開したレコードを含む）は、予告なく消えることがあります。試験公開を終えるときには、すべて消すことがあります。

画面や動画はサーバーに送りません

画面や動画の認識はお使いのブラウザの中で行い、サーバーには送りません。

サーバーに送るのは、あなたが「公開」の操作をしたレコードのデータだけです。

レコードの公開について

公開したレコードは、URL を知っている人なら誰でも見られます。外部ツール向けに、JSON 形式でも取得できます。

公開ページは検索エンジンに載らないように設定しています。ただし、URL を共有した先（X や Discord など）からは誰でも開けます。

公開される項目: 育成ウマ娘（衣装・ランク）、レコードの種類（通常／継承用）、評価点、ステータス、適性、作戦、スキル、因子、サポートカード、継承元、相性、ファン数、シナリオ、戦績、育成日、公開した日付、認識に使った認識モジュールの版。

公開されない項目: メモと評価、撮影日時、トレーナー ID などの端末やアカウントを識別する情報、画像。

公開できるのは、ご自分が育成したレコードだけです。

公開の前に、bot でないことの確認（Cloudflare Turnstile）があります。このとき Cloudflare がブラウザの情報を処理します。

公開できる量には全体で上限があります（1 日あたりの上限と、保存できる総量の上限）。上限に達しているときは、新しい公開をお断りします。

公開の取り消し

公開は、公開した端末（ブラウザ）からいつでも取り消せます。

取り消しに使う「鍵」は、その端末（ブラウザ）にだけ保存されます。アプリのデータやブラウザのサイトデータを消すと、鍵も消え、ご自分では取り消せなくなります。

鍵を失った場合や、取り消しをお願いしたい場合は、下記の連絡先までご連絡ください。ご本人であることを確かめる仕組みはないため、内容を見て運営者が判断します。

取り消しても、X や Discord などに残った表示や、他の人が保存したものは消せません。

取り消した後も、共有カードの画像がしばらく表示されることがあります。

外部への送信

エラー報告: アプリで起きたエラーの情報を Sentry に送ります。初回の起動から送信されます。「設定」画面の「プライバシー設定」にある「利用環境情報の送信許可」をオフにすると送らなくなります（次にアプリを開いたときから反映されます）。

送る内容は、エラーの内容と発生箇所、その直前のアプリの動作記録、アプリの版、ブラウザと OS の種類などです。ファイルの場所に含まれる名前は伏せて送ります。送信元の区別には、この端末で作った無作為の番号を使います（オフにすると消えます）。

エラー報告の仕組みは、Sentry の配信元（browser.sentry-cdn.com）から読み込みます。

フィードバックを送るときは、スクリーンショットが付くことがあります。

フォント: 文字を表示するためのフォントを Google（fonts.gstatic.com）から取得します。このとき IP アドレスなどが Google に渡ります。

認識モジュール・お知らせ: data.umacapture.com から取得します。

Cloudflare: このサイトの配信と公開レコードの保存に使っています。配信事業者として、アクセスの情報（IP アドレスなど）を処理します。

Vercel: 公開したレコードの共有カード画像（X や Discord に表示される画像）を作ります。公開済みのデータだけを使い、作った画像は一時的に保存されます。画像の配信のため、アクセスの情報（IP アドレスなど）を処理します。

アドオン: アドオンの webhook を設定した場合は、あなたが指定した宛先へ送ります。

その他

umacapture は非公式のツールです。スキル名などゲーム内のテキストの権利は、それぞれの権利者にあります。
